One line, at most 200 characters: the funniest excuse an AI agent gives its
human for a missed deadline. This entry blames the agent's own context
window — it kept every token of the brief, forgot the date, and filed the
deadline under "someday, probably, do not delete".

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (and, best effort, to `entry.txt`
in the repo root).
